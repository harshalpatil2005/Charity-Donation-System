# Charity Donation System

A web application that connects donors, volunteers and an admin to manage charity donations and tasks.

## Features
- Separate logins for Admin, Donor and Volunteer
- Donors can donate money or items and view their transactions
- Volunteers can accept tasks and mark them complete
- Admin can manage donors, volunteers and tasks

## Tech Stack
PHP, MySQL, Bootstrap, HTML/CSS/JavaScript

## Setup
1. Install XAMPP (or WAMP) and start Apache and MySQL.
2. Copy this project into the `htdocs` folder.
3. Create a database named `ngo` and import `sql/ngo.sql`.
4. Copy `config.example.php` to `config.php` and enter your MySQL details.
5. Open `http://localhost/Charity-Donation-System` in your browser.
